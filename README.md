# 🩲 Undies Chess

A fully playable chess game where the pieces have finally put some clothes on.

**Undies Chess** is a C++ chess game built with [raylib](https://www.raylib.com/) and developed by Kaiju Interactive. It replaces traditional chess pieces with underwear-themed sprites while retaining the rules and strategy of chess.

## 🎮 Features

- Complete playable chess game
- Player vs. Player mode
- Player vs. Computer mode
- Three AI difficulty levels:
  - **Loose Fit**
  - **Snug Fit**
  - **Tight Undies**
- Custom underwear-themed chess pieces
- Title screen and graphical interface
- Legal move validation
- Check and checkmate handling
- High-quality-of-life gameplay improvements
